# CG 06: External Dependencies and Database Access Points

## 1. External dependencies

| Dependency | Used by | Evidence | Risk note |
|------------|---------|----------|-----------|
| PHP runtime + extension **`mysqli`** | `config/db.php` and 20 scripts | `new mysqli` (db.php L18); 28 prepare + 16 query call sites | hard dependency, no abstraction |
| PHP **sessions** | login, logout, auth, auth/index | `session_start` x4, `session_destroy` | state kept server-side |
| PHP `password_*` functions (PHP ≥ 5.5) | `register.php` L50, `login_handler.php` L50 | `password_hash`, `password_verify` | none |
| **MySQL/MariaDB server**, database `library_db`, charset `utf8mb4` | `config/db.php` L12-25 | host `localhost`, user `root`, empty password | credentials hard-coded |
| Web server (Apache, e.g. XAMPP/WAMP/MAMP) | `config/paths.php` uses `$_SERVER['DOCUMENT_ROOT']` | README prerequisites | `BASE_URL` computed from document root |
| **Font Awesome 6.5.1** (CDN: `cdnjs.cloudflare.com`) | `includes/header.php` L35, `auth/register.php` L78 | `<link ... href="https://cdnjs...">` | no `integrity` attribute; icons vanish offline |
| Inline SVG icons | `auth/index.php` (login page) | `xmlns="http://www.w3.org/2000/svg"` x5 | login page does not need Font Awesome |
| Local assets | `style.css`, `auth.css`, `validate.js` | referenced via `BASE_URL` | none |

No Composer, no framework, no third-party PHP library, no JavaScript library.

### Connection point

`config/db.php` L18 creates the single global `$conn` as a **side effect of being included** (no function, no singleton). All 20 including scripts share that global variable by name.

## 3. Findings

| Ref | Evidence | Status |
|-----|----------|--------|
| CG-17 | **No data-access layer.** SQL is embedded directly in 20 page scripts that also parse input and print HTML. Persistence, business rules and presentation are tightly coupled in every script. | **Confirmed** |
| CG-18 | **Duplicated queries/logic:** the issued-records JOIN (twice in `return.php`), the active-loan guard (`books/delete.php`, `members/delete.php`), the ISBN/e-mail uniqueness checks (add vs edit), and the copy-count updates (issue, return, `books/edit.php`). | **Confirmed** |
| CG-19 | `$conn` is a global created at include time and closed by hand 48 times; error paths that `die()`/`exit` skip some `close()` calls. PHP releases it at script end, so this is cosmetic. | **Confirmed** (low) |
| CG-20 | Font Awesome is the only third-party runtime asset and it loads from a public CDN without Subresource Integrity. | **Confirmed** |
| CG-21 | Transactions are used in only 2 of the 20 SQL-touching scripts (`issue.php`, `return.php`). Other multi-step operations (check, then insert/update) rely on the database constraints alone. | **Confirmed** |
