# Function and Dependency Analysis: Library Management System

Location: `docs/reverse-engineering/code/call-graphs/`

## 1. Method

1. **Identify** important function calls and relationships between source files → [00_function_inventory.md](00_function_inventory.md)
2. **Construct call graphs** for representative workflows → files 01-05 (Mermaid diagrams)
3. **Identify external dependencies and database access points** → [06_external_dependencies_and_db_access.md](06_external_dependencies_and_db_access.md)
4. **Document circular dependencies, tight coupling and unclear responsibilities** where verified → [07_coupling_and_responsibility_findings.md](07_coupling_and_responsibility_findings.md)

Include tables, fan-in counts, the database access table and the cycle check are **generated by script from the uploaded source**, not typed by hand. Line numbers refer to the uploaded zip.
